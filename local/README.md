# local/

Your own files go here. Git ignores everything in this folder except this
note, so nothing here is ever committed.

```
local/
  ipl.bin            your GameCube IPL dump (from Swiss); the build scripts
                     copy it to the virtual boot partition automatically
  reference/         videos or captures of the real console, for comparing
```

Any `ipl.bin` name works for the dump as long as the file is `local/ipl.bin`.
